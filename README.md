# DevCareerOS 

DevCareerOS is a full-stack personal career management platform designed for students and developers.

The platform helps users manage their complete career journey from one place.

## Core Modules

- Job Application Tracker
- Skill Progress Tracker
- Project Manager
- DSA Progress Tracker
- Resume Manager
- Interview Tracker
- Career Analytics
- GitHub Activity
- Career Goals

## Planned Technology Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- MongoDB Atlas

### Authentication
- JWT
- bcrypt

### Tools
- Git
- GitHub
- Postman
- Docker
- GitHub Actions
